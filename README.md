## Prerequisites
This application can only be run if you have Python installed or run it through the IDE of your choice.

### Applications and Software
- **Python** - [Python.org](https://www.python.org/) or through your operating system's package manager.
- **Integrated Development Environment** - A good example would be [VSCodium](https://vscodium.com/), but anything will do as long as it can run Python programs.

## Installation
```  
mkdir ~/Code/escape/

git clone https://github.com/BenjaminSLS/CLI-Escape

or

mkdir ~/Code/escape/

Download the files and move them to the desired directory.

Notes:
All steps can be done using the https://tangled.org/benjaminsls.tngl.sh/CLI-Escape repository as well.
```
## How to Play
```
1.
  - Move to the directory the game is saved in.

  - python game.py
2.
  - During any dialog press enter to move forward.

  - Either the number next to or typing the name of a location can be used to move to it.

  - Typing 'exit' allows you to exit the game.

  - Whether a piece of text is capitalized or not never matters within the game.
```
